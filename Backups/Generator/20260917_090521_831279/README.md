# Aviones de Papel VR

## Jugar con Oculus (recomendado)

1. Conecta el casco Meta/Oculus y abre PC Link / SteamVR.
2. En Unity: **Aviones de Papel VR → Modo Oculus VR (mandos visibles)**
3. Pulsa **Play** ▶

Escena: `Assets/AvionesPapelVR/Scenes/Game_VR_Oculus.unity`

Verás el XR Origin con los **mandos Oculus** como en la escena por defecto.

### Controles Oculus

| Input | Acción |
|-------|--------|
| Trigger / A | Empezar / confirmar |
| Stick izq/der | Elegir avión |
| Grip | Agarrar avión de la mesa |
| Lanzar el avión | Empieza el vuelo |
| Stick izquierdo | Mover en vuelo |
| Stick derecho | Mirar / dirigir |
| Trigger derecho | Disparar |
| Grip izquierdo | Turbo |
| A | Misil |
| B | Bomba |

## Jugar solo teclado (sin casco)

**Aviones de Papel VR → Construir Juego Jugable 100%**  
Escena: `Game_Playable`
